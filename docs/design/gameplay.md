# 게임성 설계

> 게임성 논의에서 확정된 사항을 누적 기록한다.

## 판결 결착 연출 (확정)
- 실제 법원은 법봉을 쓰지 않는다(1966년 폐지 `[확인필요]`). 그래서 **법정 안 묘사에는 법봉이 등장하지 않는다**
- **기본 결착(실제 절차)**: 판결서 서명날인 `[형소법 §41, 확인필요]`. 도장을 찍는 "탁" 소리를 결착 순간으로 쓰고, 주문 낭독을 3박자로 끊어서 리듬을 준다
- **덧입히는 연출(비현실 레이어)**: 법봉 3타(땅! 땅! 땅!)는 UI·화면 전환 레이어에서만 울린다. 작중 인물은 아무도 법봉을 쓰지 않는다. 판사의 내면에서 울리는 소리로 취급한다
- 보류: 후반부에 법봉 소리를 약하게 하거나 없애서 유스티티아 테마와 엮는 반전 장치. 시놉시스와 맞는지 확인한 뒤 결정
