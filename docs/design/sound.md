# 소리 (대사 블립 + 효과음)

대화가 주 콘텐츠라서 대사 연출과 효과음을 같이 설계한다. 더빙 대신 뭉뚱그린 목소리(블립) + 글자 타이핑.

## 구현 (`src/ui/audio.ts`)
- 파일 없이 Web Audio로 합성. 나중에 실제 음원으로 바꿀 땐 `play()`/`blip()` 안쪽만 교체
- 첫 터치·키 입력 전에는 브라우저가 소리를 막으므로 그 전 요청은 버린다(`installAudioUnlock`)
- 설정(효과음·대사 소리 켜기/끄기, 글자 속도 보통/빠르게/즉시)은 왼쪽 위 [소리] 버튼, localStorage에 저장
- 소리 실패는 전부 삼킨다(게임 진행에 영향 없음)

## 대사 블립
- 글자 두 개에 한 번 짧은 소리. 인물마다 음색·높이가 다르다: 재판장(낮은 삼각파), 참여관, 검사(거친 사각파), 변호인, 증인(높고 맑음), 피고인(낮고 둔함)
- 음높이는 글자(한글 모음)에 따라 흔들린다. 같은 글자는 늘 같은 음이라 뭉뚱그린 말소리처럼 들린다
- **재판장 속생각(`thought`)도 소리가 있되 아주 작고 부드럽게**(말이 아니라 생각이라는 구분)
- 문장 부호 뒤에는 숨 고르기(쉼표 90ms, 마침표 170ms, 말줄임표 220ms)

## 글자 타이핑
- DOM에는 늘 전체 글이 있고 아직 안 찍힌 부분만 투명(레이아웃·읽기 도구·테스트가 흔들리지 않음)
- 첫 입력(▼·화면 터치·Space/Enter)은 글을 끝까지 보여 주고, 다음 입력이 넘긴다
- 움직임 줄이기 설정이면 즉시 표시(소리는 한 번)

## 효과음
법봉·도장(선고), 종이 집기/내려놓기(책상 서류), 마이크(발언)·제지, 필수 발언 신호음, 이의 제기, 이의 결정(인용/기각), 기물 신뢰/배척, 판단 확정, 회상, 대조에서 걸림.

## 아직 없음
- 서류 넘기는 소리(증거목록 확대 등), 판결서 작성, 양형 천칭 올리기, 단계 전환 소리
- 대사 소리를 필수 발언 대목에서 낮추기, 실제 음원 교체
