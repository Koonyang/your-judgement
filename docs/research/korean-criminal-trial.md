# 대한민국 형사재판 고증 노트 (1차)

> 게임 "Your Judgement" 고증용. 2차 자료(법률 칼럼·기사) 기반 1차 정리. **[확인필요]** 표시는 조문/판례 원문 대조 필요.

## 1. 1심 공판 흐름
1. **모두절차**: 진술거부권 고지 → 인정신문(인적사항) → 검사 모두진술(공소사실 요지) → 피고인 모두진술(인정/부인) → 재판장 쟁점정리
2. **증거조사**
   - 검사가 증거목록 제출 → 피고인·변호인이 증거별 **동의/부동의** 의견
   - 동의 증거: 바로 증거로 사용 가능. 동의 ≠ 유죄 인정(증거능력과 증명력은 별개)
   - 부동의 증거(특히 진술조서): 원진술자를 증인으로 불러 신문해야 사용 가능하거나, 아예 사용 불가
   - 서류증거는 요지 고지 방식으로 조사 [확인필요: 형소법 292조]
3. **증인신문**: 인정신문·선서 → 주신문(신청측) → 반대신문 → 재주신문 → **재판장 보충신문** → 이후 추가 신문은 재판장 허가
4. **피고인신문**: 증거조사 후, 필요 시
5. **결심**: 검사 구형 → 변호인 최종변론 → 피고인 최후진술
6. **선고**: 결심 후 통상 **3주~1개월 뒤** 별도 선고기일. 자백 단순사건은 첫 기일에 결심까지 끝나기도 함

## 2. 법정의 실제 모습 (역전재판과의 차이)
- 대부분 서면 공방. 법정 구두 공방은 짧음
- 단독판사 기준 기일을 **5~10분 단위**로 잡고 반나절에 수십 건 처리. 증인신문 있으면 30분~2시간
- 선고기일은 짧게 끝남. 방청은 공개 원칙, 좌석 제한 가능
- → 게임 연출: "사건 대기열", 짧은 기일 반복, 기록 더미가 진짜 전장

## 3. 정보 차단 장치 (게임 핵심 '답답함' 소스)
| 장치 | 내용 | 게임 활용 |
|---|---|---|
| 공소장일본주의 (형소규칙 118조 2항) | 공소장에 예단 줄 서류·물건 첨부·인용 금지. 위반 시 원칙상 공소기각, 실무는 삭제 지시 수준 | 판사는 공소장 한 장으로 사건 시작 |
| 전문법칙/증거동의 | 부동의 진술조서는 원진술자 신문 없이 사용 불가 | 핵심 진술이 증거목록에서 사라짐 |
| 위법수집증거 배제 | 위법 수집 증거 증거능력 부정 | 3화 |
| 자백보강법칙 (형소법 310조) | 자백이 유일한 불리한 증거면 유죄 불가. 보강증거는 자백의 진실성 담보할 정도 필요. 제3자가 "자백 들었다"는 진술은 보강증거 안 됨 (2007도10937) | 2화 |
| 함정수사 | 범의유발형 함정수사 → 공소제기 무효 → **공소기각**(형소법 327조 2호). 기회제공형은 적법 (2005도1247, 2008도7362) | 3화 |
| 변론주의 (민사) | 당사자가 주장 안 한 사실 판단 불가 | 5화 |

- 참고: 2026년 형소법 327조 개정으로 "중대한 위법수사에 기한 공소제기"가 공소기각 사유로 추가됐다는 보도 있음 [확인필요: 시행일·적용범위]

## 4. 관할 (누가 재판하나)
- 원칙: **단독판사**(법원조직법 7조 4항)
- 예외 **합의부(3인)**: 사형·무기·단기 1년 이상 징역/금고 사건, 합의부가 스스로 결정한 사건(재정합의) 등 (법원조직법 32조)
- 위험운전치사(특가법 5조의11)는 32조 단서의 예외로 **단독 관할** [확인필요]
- → 게임 배치: 1년차 단독(절도·보이스피싱·위험운전치사), 2년차 합의부(살인·아동학대치사), 3년차 민사합의부

## 5. 양형
- 양형기준 = 형종·형량 기준 + 집행유예 기준
- **특별양형인자 → 권고영역(감경/기본/가중) 결정**, **일반양형인자 → 영역 안에서 형 조정**
- 집행유예: 긍정적/부정적 주요참작사유 + 일반참작사유로 판단
- 예: 위험운전치사 기본 권고 징역 4~8년, 처벌불원(합의) 확보 시 감경영역 2~5년 [보도 기준, 확인필요]
- 실제 논란: 거액 합의·형사공탁으로 감형 → "솜방망이" 비판 (2026 창원지법 항소심 사례 등)

### 5-1. 양형기준 원문 확인 (2025. 7. 1. 기준 책자, scourt.go.kr)
- **효력**: 권고적 효력(법원조직법 §81의7 ① 단서). 양형기준을 존중해야 함(2009도11448). 벗어나면 판결서에 양형이유 기재(§81의7 ① 본문, ② 본문), 합리적·설득력 있게(2010도7410)
- **양형기준과 항소**: 1심이 양형기준을 안 지켰다고 양형부당 항소이유가 당연히 인정되지 않고, 지켰다고 양형부당 항소가 금지되지도 않음
- **복수 특별양형인자 평가**: ① 같은 수의 행위인자는 행위자/기타인자보다 중하게 ② 같은 성격끼리는 동등(개수로 상쇄) ③ 그래도 안 정해지면 종합 판단. 처벌불원은 살인·성범죄·강도·횡령배임·약취유인·사기·절도 등에서 행위인자와 동등하게 평가 가능
- **권고 형량범위 특별 조정**: 가중영역에서 특별가중인자만 2개 이상이거나 가중이 감경보다 2개 이상 많으면 상한을 1/2까지 가중. 감경영역은 대칭으로 하한을 1/2까지 감경
- **집행유예 권고 기준**: 주요참작사유가 일반참작사유보다 중함. 주요긍정만 2개 이상 또는 주요긍정이 주요부정보다 2개 이상 많으면 집유 권고, 반대면 실형 권고. 일반사유 차이가 더 크거나 둘 다 아니면 종합 판단
- **이중평가**: 일반 원칙 문구는 없음. 범죄별로 "중복하여 적용하지 아니한다" 규정이 개별적으로 있음(예: 살인 피해자 유발)
- 양형기준 해설 원문: https://www.scourt.go.kr/sc/krsc/pdf/2025_sentencing_guidelines.pdf

### 5-2. 항소 관련 (2차 자료)
- 2015도3260 전합: 양형 조건 변화 없고 1심 형이 재량의 합리적 범위 안이면 항소심이 존중 (판시사항, 전문 [확인필요])
- 검사 항소 기준: 선고형이 구형의 1/2 미만이면 항소한다는 대검 예규가 보도됨(2025 대장동 항소 포기 보도). 예규 원문 비공개
- 형소법 §361의5, §364, §368 조문 원문 [확인필요]: law.go.kr 본문이 스크립트 로딩이라 이번에 못 가져옴

## 6. 확정판결과 재심 ⚠ 시나리오 영향
- 재심은 **유죄 확정판결에 대해, 선고받은 자의 이익을 위해서만** 청구 가능 (형소법 420조)
- **무죄 확정 → 일사부재리**(헌법 13조 1항). 나중에 진범임이 밝혀져도 같은 사건으로 다시 처벌 불가 [확인필요: 판례]
- 사유 예: 새롭고 명백한 증거(420조 5호, 2005모472 전합: 기존 증거와 종합 판단)
- → 초안의 "무죄 사건 재심" 설정은 법적으로 불가해서 폐기함. 대신 최종 6화(민사)에서 4화의 진실이 드러나지만, 일사부재리 때문에 아무것도 할 수 없는 구조로 변경 (docs/story/synopsis.md)

## 7. 남은 조사 과제
- 판결서 구성(주문/이유/양형이유), 선고 낭독 실제 문구
- 구속기간(1심), 보석, 국민참여재판 대상
- 합의부 내부 합의 실무(재판장·주심·배석 역할)
- 절도·사기(보이스피싱)·아동학대치사 양형기준표 원문 (책자 확보: 5-1 출처 PDF에서 범죄별로 발췌하면 됨)
- 민사 변론주의·석명권 한계, 유언 무효 소송 쟁점
- 판례 원문 대조 (law.go.kr / glaw.scourt.go.kr)
