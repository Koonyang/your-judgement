# 진행 상황 (다음 세션 인수인계)

> 마지막 갱신: 2026-11-19

## 확정된 것
- 장르: 2D 도트 감성 재판 게임. 플레이어는 대한민국 판사
- 최우선 원칙: **실제 재판 절차의 철저한 고증**
- 메시지·스토리·에피소드 구성: `docs/story/synopsis.md`
- 고증 노트: `docs/research/korean-criminal-trial.md`
- 기술: **웹 (TypeScript + Phaser 3 + Vite)**. 시나리오는 코드와 분리된 데이터 파일로 두고, 도트 아트는 일단 플레이스홀더를 쓰고 나중에 교체
- 첫 구현 목표: **1화 수직 슬라이스**
- 게임성 설계 문서: `docs/design/gameplay.md` (평가 기준(여유폭·항소 발생·항소심 판정·기울어짐) 확정, 기본 틀 "검증하는 게임", 쟁점 보드, 도우미 NPC, 상시 신문 제지, 판결 결착 연출 확정, 판결·양형 단계, 모두절차·피고인신문·결심 확정)

## 플레이어 행동 초안 (형사, 게임성 논의 때 확정)
1. 공판 전: 공소장·피고인 의견서만 열람 (공소장일본주의, 증거기록은 채택 후 해금)
   - 모두절차: 자동 진행, 쟁점정리 때 쟁점 보드 자동 생성 **설계 확정**
2. 증거 채부 (고증 우선, 진행 버튼 위주. 부동의 조서는 표목만 보이고 잠김) **설계 확정**
3. 증인신문 (청취 + 제지 + 이의 결정 + 쟁점 보드 연동 보충신문) **설계 확정**
   - 피고인신문 (증인신문 장치 재사용, 진술거부는 카드 없음) / 결심 (자동, 구형은 양형 화면에 앵커로 표시) **설계 확정**
4. 유무죄 판단 **설계 확정**
5. 양형·판결서 (인자 카드 조립 + [추가로] 자유 문구로 가치관 여유폭, 크게 벗어나면 카드 기반 이탈 사유) **설계 확정**
6. 결과 (항소 주체 모델링, 항소심 파기/유지, 일부 사건은 진실 공개) **설계 확정**

## 다음 단계
1. **게임성 설계 계속**: 4~5단계(채부·증인신문)는 `docs/design/gameplay.md`에 확정. 판결·양형, 모두절차·피고인신문·결심, 평가 기준도 확정. 형사 게임성 설계 완료
   - 표목 선입견 장치와 엔딩 분기(선을 넘었는가) 확정. 엔딩은 거울형이고 진엔딩은 두지 않는다(synopsis). "기울어짐" 기록은 중간 형태 엔딩의 재료. 회차 배치와 결말 수는 미정
2. 설계 문서 작성 → 승인 → 구현 계획 → 1화 구현
3. 고증 노트의 [확인필요] 항목은 원문(law.go.kr, 양형위원회)과 대조
