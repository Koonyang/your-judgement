- 최우선 원칙: **실제 재판 절차의 철저한 고증**
- 메시지·스토리·에피소드 구성: `docs/story/synopsis.md`
- **전체 스토리라인 구상 v2** (2026-11-20, 구현 전): `docs/story/storyline.md`. 0장 프롤로그 + 8화 구성(신규 3화 택배 상자, 6화 국민참여재판), 복선 지도(P-1~3, L-1~7), 신분을 보직 연차로 수정, 목표 4~5시간, 대사 볼륨 1화의 2~3배(정보:캐릭터 ≈ 1:1), 관통 인물, 진실 공개 정책, **고증 장부(G-1~G-43)**와 고증 시뮬레이션 기록(S-1~). 스토리 작업 때마다 장부 갱신 + 시뮬레이션 기록 추가. 1화 데이터 후속: 노은숙 대사(남편 사별), 윤상택 실직 사유는 최만호와 무관하게
- 고증 노트: `docs/research/korean-criminal-trial.md`
- 기술: **웹 (TypeScript + Phaser 3 + Vite)**. 시나리오는 코드와 분리된 데이터 파일로 두고, 도트 아트는 일단 플레이스홀더를 쓰고 나중에 교체
- 첫 구현 목표: **1화 수직 슬라이스**
- **화면 틀** (2026-11-20 구현 완료, 설계 `docs/superpowers/specs/2026-11-20-look-frame-design.md`): 판사 시점(법대에서 내려다봄, 판사 스프라이트 없음), 논리 640×360 2배 표시, 3단(법정 / 대사 줄+초상 / 책상), 팔레트 "스탠드 빛"(먹색 법정·따뜻한 책상 불빛·한지색 서류·인주 빨강), Galmuri11. 책상 위 서류를 집으면 확대 보기, [내려놓기]·바깥 클릭으로 닫기. 판결서·쟁점 보드는 끌어다 놓기(클릭도 가능). 증거목록은 B1280 양식 표(○/× 표시만)
- **양형 천칭**: 카드를 유리/불리 접시에 올림. 인자 방향은 고정(반대 접시는 튕김). 기울기는 양형기준 평가 결과(영역·특별조정·종합 판단)를 따르고 숫자 가중치는 없음. 계산 줄 ①특별인자 ②특별조정 ③일반인자 ④집행유예. 막대는 기록상 권고(R11), 일반인자는 범위 안 반쪽 음영. 접시 내용이 판결서 양형의 이유로 자동 채워짐(리듀서: 양형 단계에서 SET_JUDGMENT favorable/unfavorable 허용)
- 대사 줄은 화면 맨 아래(y290–360, 본문 13px). 선택지(이의 인용/기각, 보충신문)가 없으면 화면 아무 데나 눌러 다음. 제지는 책상 오른쪽 아래 구석의 구스넥 법정 마이크(누르면 표시등 +  "재판장: 잠깐."), 재판장 대사 중엔 비활성
- **판결서 작성**(저울질 뒤 바로, 양형 단계에서 시작): 왼쪽 빈 판결서를 누를 때마다 다음 항목(주문→범죄사실→증거의 요지→법령의 적용→양형의 이유)이 순서대로 나타나고 오른쪽 도구가 바뀐다(쓴 항목은 다시 눌러 고침, 마지막까지 써야 확정). 주문 = 권고 막대 위 스크롤로 형량(징역 ○년 ○월 자동), −/+1개월, 집행유예, 참고(권고·계산 줄). 증거의 요지 = 카드 끼우기. 양형의 이유 = 천칭 결과 + [추가로]. [판결서 확정] = CONFIRM_SENTENCING → CONFIRM_JUDGMENT(형이 없으면 주문으로). 리듀서: SET_JUDGMENT를 sentencing 단계에서도 받음
- 판결서에는 양형의 이유 유리/불리 선택 칸이 없다(천칭 접시가 채운 것을 미리보기로만). 부동의 잠긴 증거는 증거목록에 자물쇠
- 용어: 평가 기준 "기울어짐" → **"편향"**
- 수정(2026-11-20): 판결서 외 서류는 화면을 덮지 않는 종이 크기(법정이 위로 보임, 종이 안 스크롤), 법정 인물 숨쉬기 동작, 양형 천칭은 허공의 AR 연출. 서류 세로 약 85%. 양형은 ①저울질(카드·천칭·수치 없는 막대만) → ②판결(서류: 가운데 주문 빈칸 채우기 + 아래 참고로 권고·설명) 두 단계. 저울질 때 천칭은 화면 가운데(AR), 카드는 책상 위 종이
- 게임성 설계 문서: `docs/design/gameplay.md` (평가 기준(여유폭·항소 발생·항소심 판정·편향) 확정, 기본 틀 "검증하는 게임", 쟁점 보드, 도우미 NPC, 상시 신문 제지, 판결 결착 연출 확정, 판결·양형 단계, 모두절차·피고인신문·결심 확정)

## 플레이어 행동 초안 (형사, 게임성 논의 때 확정)
1. 공판 전: 공소장·피고인 의견서만 열람 (공소장일본주의, 증거기록은 채택 후 해금)

3. 증인신문 (청취 + 제지 + 이의 결정 + 쟁점 보드 연동 보충신문) **설계 확정**
   - 피고인신문 (증인신문 장치 재사용, 진술거부는 카드 없음) / 결심 (자동, 구형은 양형 화면에 앵커로 표시) **설계 확정**
4. 유무죄 판단 **설계 확정**
5. 양형·판결서 (인자 카드 조립 + [추가로] 자유 문구로 가치관 여유폭, 크게 벗어나면 카드 기반 이탈 사유) **설계 확정**
6. 결과 (항소 주체 모델링, 항소심 파기/유지, 일부 사건은 진실 공개) **설계 확정**
