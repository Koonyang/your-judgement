## 지금 상태
- **1화 수직 슬라이스 구현 완료**: 사건 대기열 → 공판 → 판단 → 선고 → 항소 → 판결 기록실. 실행 `npm run dev`, 테스트 `npm test`, E2E `npm run build && npm run e2e`
- **검수 사이트**: 고정 아티팩트 "Your Judgement"(https://claude.ai/artifact/5LGyr1X6pteJBTM8oxQsUe). 반영은 스킬 `/deploy-review`(`deploy/prepare-review.mjs`가 테스트·영수증 숫자·게시 맵 처리)
- **주인공**: 22세 임용 → 33세 붕괴 사고로 실명 → 36세(2026. 2.) 복직한 판사. 시력은 **막간 1까지 플레이어에게 숨기는 서술트릭**(촉각 묘사·말하는 사람만 밝은 화면이 복선, 막간 1 회피 신청 장면에서 공개, `storyline.md` §1·P-4). 속생각 말투는 20~30대 구어. 1화 반영됨. "집중해서 듣기"는 설계 초안만(`gameplay.md`)
- **스토리**: 0장 + 8화 + 사건 묶음 2개 + 막간 2개, 목표 4~5시간. `docs/story/storyline.md`(v3: 인물·복선 지도·고증 장부 G-1~48·시뮬레이션 S-1~12). 시놉시스 `docs/story/synopsis.md`
- **구현된 장치**: 판사 시점 법정(말하는 사람만 밝음), 대사 줄(화면 터치로 넘김), 재판장 속생각(화자 `thought`, 공판조서 제외), 제지 마이크, 이의 결정, 보충신문, 쟁점 보드, 양형 천칭 → 판결서 작성, 선고 연출, 판사 닉네임 도장(한글·한자 세로 / 영문·숫자 가로, 8자), 서류 집어 들기/내려놓기 애니메이션, 인물 짧은 이동(증인 난간 문 ↔ 증언대, 피고인 자리 ↔ 증언대), 화자 밝히기 + 머리 위 말소리 표시, 법정 밖 단계는 판사실 장면(책상 띠 없음), 법정 띠 170px·책상 120px

## 작업 규칙 메모
- 시나리오 테스트는 줄 id로 진행한다(`tests/scenario/play.ts`의 `to('owner_9')`, `toSupp()`, `toPhase('verdict')`). 대사를 추가해도 테스트 숫자를 고칠 필요 없다

- 법령·판례 원문은 `scripts/law.mjs`(국가법령정보 Open API, `LAW_OC` 필요). 클라우드 세션 IP 12개(160.79.106.x) 등록됨, 나머지 IP로 나가면 스크립트가 재시도. 다 막히면 `curl https://checkip.amazonaws.com`으로 새 IP 확인해 사용자에게 등록 요청
