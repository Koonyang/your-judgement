# 때깔 틀 작업 설계 (판사 시점 + 책상)

> 2026-11-20 브레인스토밍 결과. 시안: 대화 중 목업(스탠드 빛 1안). 최종 도트 에셋은 범위 밖

## 1. 왜

1화를 처음부터 끝까지 클릭으로 진행할 수 있게 됐지만, 지금 화면은 색 사각형과 화면을 덮는 HTML 패널뿐이다. 2화 데이터를 쓰기 전에 화면 틀을 먼저 잡는다. 대사 길이, 한 화면에 들어가는 기록 분량, 템포가 화면 틀에 따라 달라지기 때문이다. 또 "끼운다"고 했는데 실제로는 클릭 토글이라 기대한 손맛이 없었다(설계 문서 `ep01-vertical-slice.md`는 원래 드래그 슬롯이었다).

## 2. 목표 / 비목표 / 반목표

**목표**
- 판사 시점 구도: 법대에 앉아 법정을 내려다본다. 판사 스프라이트는 없다
- 화면 3단: 위 법정 전경, 가운데 초상화+대사창, 아래 내 법대 상판(책상)
- 책상 위 서류를 집어 들면 확대돼서 읽힌다. 카드는 끌어다 슬롯에 놓는다(클릭으로도 가능)
- 팔레트 "스탠드 빛" 적용, Galmuri 폰트 실제 로드
- 1화를 새 틀로 처음부터 기록실까지 진행 가능

**비목표 (이번에 안 함)**
- 최종 도트 그림(인물·배경). 플레이스홀더 규격만 정한다
- 증거목록 결정란에 플레이어가 ○/×를 직접 기입하는 **게임 규칙 변경**. 지금 엔진은 채부를 진행 버튼으로 처리하므로 이번엔 표시만 B1280 양식으로 바꾼다. 직접 기입은 게임성 설계에서 따로 결정
- 사운드, 복잡한 애니메이션, 2화 데이터

**반목표 (이렇게 되면 실패)**
- 페이퍼 플리즈처럼 보이는 것: 화면 전체가 고르게 칙칙한 저채도, 승인/거절 도장 찍기 동작. 도장 대신 ○/× 기입(고증 노트 2-1)
- 역전재판식 연출
- 기록 가독성이 지금보다 나빠지는 것
- 기존 테스트(vitest, e2e 스모크)가 깨진 채로 끝나는 것

## 3. 결정 사항 (사용자 결정)

- 톤: 진지한 게임. 시안 B(어둡고 차가운 법정) 계열 → 책상과 겹쳐 페이퍼 플리즈 느낌이 나서 **"스탠드 빛"** 으로 확정: 법정은 먹색 실루엣, 내 책상에만 따뜻한 불빛, 서류는 한지색, 강조색은 인주 빨강
- 시점: 판사 시점(1인칭, 법대에서 내려다봄)
- 해상도: 페이퍼 플리즈 수준. **논리 640×360, 2배 표시(1280×720)**
- 책상 구성 채택. 끌어다 놓기 조작
- 구현 방식 **A: 책상도 HTML** (아래 4절)

## 4. 접근 방식

| 방식 | 내용 | 결과 |
|---|---|---|
| **A. 책상 HTML** | Phaser는 법정 전경(+선고 장면)만. 대사 줄·책상·확대 서류는 HTML. 기존 패널을 책상 위 물건 → 확대 보기로 재사용 | **채택**. 패널 코드·testid·테스트 재사용, 한글 선명. 단점: 스탠드 빛을 CSS로 흉내 |
| B. 책상 Phaser | 책상·서류·카드를 스프라이트, Phaser 드래그. 확대만 HTML | 기각. 상태 동기화 이중, e2e 재작성 |
| C. 전부 Phaser | 글자까지 캔버스 | 기각. 1화 설계 때 한글 장문 때문에 이미 기각 |

## 5. 설계

### 5.1 좌표계와 해상도
- Phaser: `width: 640, height: 360, zoom: 2, pixelArt: true`. `SEATS` 좌표는 새 구도로 다시 잡는다(640×360 기준)
- HTML: `#ui-root`를 640×360 논리 좌표로 작성하고 `transform: scale(2)`(원점 좌상단)로 키운다. 그래서 CSS 숫자는 전부 논리 픽셀이다
- 창 크기에 맞춘 정수 배율 조정은 하지 않는다(지금도 1280×720 고정). `[빌더 판단]` 필요하면 나중에

### 5.2 화면 3단 (논리 픽셀)
```
y   0–150  법정 전경 (Phaser)        검사석 | 증인석(정면, 가장 큼) | 변호인·피고인석, 뒤 방청석, 앞 참여관 뒤통수
y 150–200  대사 줄 (HTML)            [초상 42×42] 이름표 + 대사, [다음]·제지 등 버튼
y 200–360  책상 (HTML)               단계별 물건이 놓인다. 스탠드 빛
```
- 법정 좌우 배치: 판사 시점에서 검사 왼쪽, 변호인·피고인 오른쪽은 **임시** `[확인필요]`(기존 항목 유지)
- 화자 강조: 말하는 사람 자리만 밝게, 나머지 어둡게(지금 `glow`/`dim` 대체). 법정 전체는 먹색 실루엣 톤
- 초상화: 화자별 42×42 플레이스홀더(색 블록 + 이름 첫 글자 정도). 이미지 키는 화자 문자열(지금 규칙 유지) → 나중에 교체
- 단계가 법정 밖(대기열·판결 이후)이면 법정 전경 영역은 어둡게 두고 책상만 쓴다. `[빌더 판단]` 판결 단계에서 책상을 위로 넓힐지

### 5.3 책상 물건 (단계별)
지금의 상단 탭(기록·증거목록·쟁점 보드)과 단계별 패널을 책상 위 물건으로 바꾼다. 물건을 클릭하면 **확대 보기**(지금 패널을 새 스타일로)가 열린다. testid는 유지: `tab-docs`·`tab-evidence`·`tab-board`는 책상 물건 버튼의 testid가 된다.

| 단계 | 책상 위 | 확대 보기 |
|---|---|---|
| docket | 사건 서류철 더미 | 대기열(지금 docket 패널) |
| pretrial | 공소장, 의견서 | 기록+형광펜(docs) |
| opening~closing | 기록, 증거목록, 쟁점 메모 | docs / evidence / board(drawer) |
| verdict | 쟁점 보드 | board(main) |
| sentencing | 양형표 | sentencing |
| judgment | 판결서 초안 + 카드들 | judgment (카드 드래그) |
| appeal / record | 결과 서류 / 기록철 | result / record |

- 증거목록 확대 보기는 **B1280 양식 칸 배치**로 표시(고증 노트 2-1): 순번 | 증거명칭 | 성명 | 참조사항 | 증거의견(기일·내용) | 증거결정(기일·내용) | 비고. 의견 ○/×, 결정 ○/× 기호 사용. 피의자신문조서 의견은 인정 ○·부인 ×. 결정란 값은 지금 엔진 상태(채택/잠김)에서 그대로 나온다. 엔진에 없는 칸(쪽수, 기일 등)은 비우거나 데이터에 있으면 채운다 `[빌더 판단]`
- 확대 보기 위치: 책상+대사 줄 위로 열리고 법정은 더 어둡게. 판결 단계처럼 대사가 없는 단계는 화면 전체 `[빌더 판단]`
- 지금 단계 진입 시 자동으로 서랍을 여는 규칙(pretrial→기록, evidence→증거목록)은 "자동으로 집어 든 상태"로 유지
- 모두절차 후 쟁점 보드 확인 모달(`board-intro`)도 유지

### 5.4 끌어다 놓기
- 판결서: 카드(증거·양형 인자·형광펜 문장)를 슬롯(증거의 요지 / 유리한 정상 / 불리한 정상 / 이탈 사유)에 끌어다 놓는다. 놓으면 지금 `toggle`과 같은 `SET_JUDGMENT` 디스패치. 슬롯 안 카드를 밖으로 끌면 뺀다
- 쟁점 보드: 카드를 칸에 끌어다 놓기(지금 `board-card-*` 클릭과 같은 동작)
- **클릭도 그대로 동작**: 기존 클릭 토글·testid 유지. e2e는 클릭 경로로 통과해야 한다
- 구현: Pointer Events 직접(HTML5 DnD API 안 씀). 작은 공용 헬퍼 하나(`src/ui/drag.ts`)
- 키보드 접근성: 클릭 경로가 있으므로 별도 키보드 드래그는 만들지 않는다

### 5.5 팔레트 토큰 (`style.css :root`)
시안 1안 값에서 출발, 빌더가 대비 조정 가능.

| 토큰 | 값 | 용도 |
|---|---|---|
| `--court` | `#0e0f13` | 법정 벽 |
| `--court-2` | `#15161c` | 법정 면 |
| `--court-line` | `#1d1f26` | 법정 선 |
| `--desk` | `#3b2a1c` | 책상 |
| `--desk-top` | `#4f3926` | 책상 모서리 |
| `--hanji` | `#e8dcc2` | 서류 |
| `--hanji-2` | `#d6c7a6` | 서류 칸·카드 |
| `--ink` | `#2a221b` | 글자 |
| `--seal` | `#b8382e` | 인주 빨강(○/×, 강조, 이름표) |
| `--lamp` | `rgb(255 196 120)` | 스탠드 빛 |
| `--box` | `#121318` | 대사 줄 |
| `--box-line` | `#6b5a44` | 대사 줄 테두리 |
| `--accent` | `#e0b060` | 선택·포커스 |

- 스탠드 빛: 책상 영역에 계단식 `radial-gradient`(띠 3~4단). 서류 위에는 빛 오버레이를 약하게(가독성)
- 기존 `--wood*`, `--brass`, `--paper*` 토큰은 새 토큰으로 대체

### 5.6 폰트
- `galmuri` npm 패키지(2.40.3)를 의존성으로 추가하고 Galmuri11(+Bold)만 `@font-face`로 로드. 논리 11px(표시 22px) 기준
- Phaser 텍스트도 같은 폰트. 폰트 로드 후 장면 시작(`document.fonts.ready`)

### 5.7 선고 장면
- `PronounceScene`은 유지하고 팔레트·해상도만 맞춘다

## 6. 테스트·검증
- `npm test`, `npm run typecheck` 통과
- `npm run e2e` 스모크가 testid 수정 최소로 통과(클릭 경로)
- 드래그 경로 확인: e2e 스모크에 판결서 카드 1장을 드래그로 끼우는 단계 하나 추가
- 단계별 스크린샷(대기열·공판 전·신문·판결서)으로 눈 확인 후 사용자에게 보여 준다
